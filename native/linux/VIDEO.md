# Linux 原生视频发送

适配 Linux 微信 4.1.13.26，使用项目的版本指纹检查与原生发送桥接。文件传输助手、私聊和群聊分别使用同一个 2 秒 MP4 实机确认显示为可直接播放的视频；不同编码、尺寸和时长没有全面实测。

管理台在“群聊与会话”选择“视频（MP4）”并填写 Linux 本机绝对路径。插件声明 `video.send`，调用 `ctx.send_video(chat_id, path)` 或 `ctx.reply_video(message, path)`。旧桥接未报告 `local_video` 时，视频发送保持不可用。

仅支持本地 MP4，须包含视频轨和可用时长；单次发送最多 64 MiB。发送前复制到当前用户私有目录，微信进程退出前保留快照；视频与文件共享最多 64 份和 64 MiB 的快照预算。目录、会话白名单与当前账号按连接隔离。发送结果不确定时不自动重试，须先核对微信。

测试仅覆盖短视频正常发送，不代表所有 MP4 编码、服务器、超长视频或不同微信版本均可用。
