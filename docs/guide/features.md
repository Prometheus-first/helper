# 群聊功能

先在[成员配置](./account-and-groups.md#添加一个群)中启用目标群。以下指令发送到微信群，不是在终端中输入。

## 指令一览

| 指令 | 功能 | 需要模型 |
| --- | --- | --- |
| `/help` | 查看群功能菜单 | 否 |
| `/来张图` / `/美女` | 从图库获取一张图片并发送 | 否 |
| `/绑定 昵称` | 设置本人在当前群的称呼 | 否 |
| `成语接龙` | 开启当前群的独立接龙 | 是 |
| `合并接龙` | 切换为全群抢答一条链 | 接龙使用模型 |
| `退出接龙` | 结束当前群接龙 | 否 |
| `看图猜成语` | 开启本群看图抢答，机器人发题图 | 否 |
| `/猜 四字成语` | 回答题图，也可直接发送四字成语 | 否 |
| `提示` | 逐步给出当前题目的提示 | 否 |
| `换一题` / `公布答案` | 揭晓本题并自动出下一题 | 否 |
| `退出猜成语` | 结束本群看图猜成语 | 否 |
| `/总结 昵称` | 总结该成员今天在本群的聊天 | 是 |
| `/总结群聊` | 总结今天本群全部成员的聊天 | 是 |
| `/清空` | 清除当前群的聊天文本 | 否 |
| `/切换人格 嘴臭` | 切换当前群的模型表达风格 | 设置不调用模型 |
| `/切换人格 卑微` | 同上 | 设置不调用模型 |
| `/切换人格 夸夸` | 同上 | 设置不调用模型 |
| `/切换人格 取消` | 恢复普通任务语气 | 否 |
| `/查看音色` | 查看个人音色和中文公开音色第一页 | 查询语音服务 |
| `/查看音色 2` | 翻阅中文公开音色 | 查询语音服务 |
| `/查看音色 全部` | 查看各国语言的公开音色 | 查询语音服务 |
| `/查看音色 关键词` | 搜索音色，可在末尾加页码 | 查询语音服务 |
| `/音色 名称或ID` | 切换当前群的回复音色 | 切换不调用大模型 |
| `/音色 关闭` | 当前群恢复文字回复 | 否 |

模板默认关闭需要模型的接龙、总结、艾特对话插件。先完成[模型配置](./configuration.md#大模型配置)，再启用对应插件。

## 图库图片

`image_gallery` 默认启用。群内发送 `/来张图` 或 `/美女`，机器人从免费图库取图并回复图片，不需要大模型或图库密钥。默认每群 10 秒内响应一次，支持小小 API、万站 API 或自定义 HTTPS 接口。目标群需要先加入成员配置；取图请求不包含账号、群号或聊天内容。完整配置与缓存说明见[图库图片](../messages/gallery.md)。

## 防撤回补发

防撤回分为四个独立插件，均默认开启：`anti_recall` 补发原文字、内置表情和 emoji，并重新发送已缓存的表情包；`anti_recall_image` 重发已下载的图片，`anti_recall_file` 按原文件名重发已下载的文件，`anti_recall_voice` 重发已完整接收的语音。可在网页插件管理分别开关，或在控制台使用 `disable <插件名>`。无需模型，适用范围由 `chat_allowlist` 控制；大小、缓存及下载失败限制见[防撤回与自动补发](../messages/recall.md)。

## 进群欢迎与退群提醒

在程序控制台输入 `enable group_notice` 开启，`disable group_notice` 关闭。新人加入与成员退出时自动发送一条对应通知，无需大模型。欢迎、退群提醒可以分别关闭，文案支持 `{nickname}` 占位符。

首次读取群名单只建立基线，后续确认变化才通知；重连不补发旧通知。实际时效取决于微信成员缓存更新。查询成员、群昵称与完整配置见[好友申请与群管理](./friends-and-groups.md#进群欢迎退群提醒和群友昵称)。

## 成语接龙

发送“成语接龙”后，机器人只发一个开场成语。独立模式为每位玩家维护自己的链，真正艾特该成员后点评并给出下一词。

发送“合并接龙”后，本群共用一条链，每轮只响应先到的答案，不单独艾特。发送“退出接龙”结束本群游戏。

规则为四字成语、末字接首字、必须同字、不接受同音字、同一条链不重复。格式和重复由本地校验，词义和下一词由模型判断；模型故障时保留原题。

插件名称为 `idiom_chain`。重启、微信重连或重载插件会清除未完成的局。

## 看图猜成语

在程序控制台执行 `enable picture_idiom`，并配置目标群。群内发送“看图猜成语”后机器人只发送题图。默认从[飞飞 API](https://ffapi.cn/doc/ktccy.html)获取图片和固定答案，接口或图片失败时自动改用 26 道本地题，一分钟后再尝试在线题源。无需新增 API 密钥或大模型。

直接发送四字成语或 `/猜 四字成语` 抢答。机器人真正艾特首位答对者，然后自动出下一题；可以发送“提示”“换一题”“公布答案”或“退出猜成语”。答错默认每群最多每三秒提醒一次，其余普通聊天忽略。

在线题的提示依次为答案首字、前两字，本地题的提示依次为图意、答案首字。在线出题时，每群避开最近 32 个已发送的答案，最多请求两次，仍重复则回退本地题；在线题不保证整场不重复。仅本地模式下，首题为“绕梁三日”，其后随机出题，一轮题库用完前不重复。

每个群各自进行，重连、重载或退出程序后重置。两个游戏插件都启用时，开始看图猜成语会结束本群成语接龙，反过来也一样。

插件需要 Pillow 和本机中文字体，用于绘制本地备用题；默认查找楷体、微软雅黑或黑体，可设置插件 `font_file`。在线与本地题图都缓存在 `.runtime/picture_idiom/`，文件名不含答案，图片不写入答案元数据；不分发第三方题图或系统字体。停止程序后可清理缓存。

在线请求不携带账号、群号、玩家 ID 或聊天内容。设置 `source: "local"` 可完全离线出题；超时、提醒间隔等配置见[看图猜成语配置](./configuration.md#看图猜成语)。判题按固定答案精确匹配，不使用模型判定同义词。

## 当天聊天总结

`/总结 昵称` 先通过本群成员目录找到对应 ID，再总结此人今天的有效文字。昵称重名或无法确定时，由本人 `/绑定` 一个不同称呼后再使用。

`/总结群聊` 按主要话题总结当天本群的全部成员发言，未绑定成员也参与。功能指令和机器人输出不会作为聊天内容提交给模型；内容很多时分批处理。

插件名称为 `chat_summary`，需要启用成员记录。只覆盖框架运行后实际收到的文字；图片和旧历史不参与。文本会提交给你配置的大模型服务。

## 人格切换

人格作用于当前群的模型对话、个人总结、全群总结和接龙点评。事实、成语规则和功能指令仍按原任务处理。

- 嘴臭：短促、直接的表达，模型正文限制为二十个可见字符，总结收成一句短评。
- 卑微：采用谦卑、顺从的语气。
- 夸夸：根据具体内容赞美与鼓励。
- 取消：恢复普通任务提示。

每群分别保存，重启、午夜清理和 `/清空` 不重置选择。切换后，尚未发出的旧人格模型结果会取消。插件名称为 `personality`，提示词在 `wxbot_framework/personality.py`。

## 艾特机器人对话

从微信成员列表真正艾特机器人，并附上问题即可触发。普通文字里手打的 `@昵称` 不触发，艾特别人也不触发。

回复使用本群当前人格，文字回复会真正艾特发言者，并携带此人在本群当天此前最多十条有效文字。不混入其他人、其他群、控制指令和机器人自己的输出。

插件名称为 `mention_chat`，需要有效模型配置和成员记录。清空、跨天、账号切换或人格变化会取消尚未发出的旧回复。

同时启用 `voice_reply` 并选择音色后，艾特对话会发送微信语音条，保留当前人格和上下文。按群切换、密钥配置和失败回退见[语音回复](../messages/voice.md#fish-audio-文字转语音)。
