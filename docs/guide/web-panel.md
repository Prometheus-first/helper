# 本地网页管理台

在项目目录运行：

```powershell
python web.py
```

程序会打开 `http://127.0.0.1:8765`。管理台自动列出已登录的微信，由你勾选并点击“启动所选”后才连接对应账号。网页使用项目现有的 JSON 配置和 `.runtime/` 数据，不需要安装额外的 Web 框架或构建前端。

Windows 也可以直接双击项目里的 `start_web.bat`，自动打开浏览器。启动器依次查找 `WXBOT_PYTHON` 指定的解释器、项目 `.venv`、系统 `python` 和 `py -3`；失败时保留窗口显示原因。关闭服务请按 Ctrl+C。

也可以使用 PowerShell 启动脚本：

```powershell
.\start_web.ps1
```

右上角可切换亮色／暗色。首次跟随系统，手动选择后由浏览器记忆。

## 启动微信并获取登录二维码

运行概览中点击“登录微信”，管理台会启动微信并显示登录二维码；用手机微信扫码并确认后，账号会出现在已登录列表中。你仍需选择账号并启动机器人。当前支持已核对指纹的微信 4.2.0.11，微信登录窗口需要保持打开且未最小化。微信有时显示登录按钮而不是二维码，此时请在微信窗口操作并在手机上确认。

管理台也提供本地接口。请求需携带页面的 `X-Helper-Token`，请求和二维码只应留在本机：

| 接口 | 用途 |
| --- | --- |
| `POST /api/wechat-login/start` | 请求体 `{}`，启动微信并返回 `attempt_id` 和 `pid` |
| `POST /api/wechat-login/attach` | 请求体 `{"pid": 1234}`，使用已打开的未登录微信进程 |
| `GET /api/wechat-login/status?attempt_id=...` | 查询状态；`qr_available` 时返回 PNG 的 `qrcode_base64` |
| `POST /api/wechat-login/cancel` | 请求体 `{"attempt_id":"..."}`，释放读取句柄，不退出微信 |

状态还包括 `starting`、`waiting`、`logged_in` 和 `exited`；`logged_in` 返回当前进程的 `wxid`。登录尝试保留 5 分钟，超时后可重新开始；二维码本身的有效期由微信决定，过期时需要在微信刷新。二维码内容只在内存中处理，不写入日志和文件，也不自动启动机器人。

## 同时运行多个机器人

无需手填 wxid、手动绑定账号或先创建机器人：

1. 在电脑微信完成需要使用的账号登录。
2. 在“已登录微信”中核对微信名、wxid 和进程，勾选需要运行的账号。
3. 点击“启动所选”，可一次启动多个账号；未勾选的账号不受影响。
4. 首次使用的新账号，可先在顶部“当前账号”选择它，配置群聊、模型和插件，再点击该行“启动”。切换账号只准备配置，不启动机器人。
5. 顶部“当前账号”用于切换插件、群聊、模型和日志的管理对象。每行“启动”只启动该行账号，运行后变为“停止”；不改变顶部选择，也不影响其他机器人。

原有账号会自动对应已有配置，保留密钥、群聊、插件和历史，重新登录后进程 PID 变化也能找到原配置。首次使用且默认配置尚未对应账号时，所选第一个账号使用默认配置；之后的新账号使用空模板，不复制其他账号的密钥、群聊或历史。每个机器人由独立 Python 工作进程运行；配置、数据库、语音与媒体数据、日志按工作目录分别保存。附加机器人位于 `.runtime/robots/<实例ID>/`，列表保存在 `.runtime/robots/index.json`，均被 Git 忽略。题图缓存及少量原生请求临时文件还会使用项目 `.runtime/`，按账号或随机请求 ID 区分。

页面约每 10 秒识别一次账号，也可手动刷新。刷新或重新打开页面不会自动勾选、启动机器人；关闭浏览器后，已经运行的机器人继续运行。批量启动会逐个显示提交结果，某个账号失败不影响其他所选账号；请求已提交后，实际连接状态以列表和日志为准。

如果账号退出或进程变化，旧选择会失效，需要刷新后重新选择。同一账号的重复登录进程或重复配置会被标记并禁止启动；同一微信进程仍有原有跨项目占用保护。微信扫码和手机确认在微信客户端完成。`python main.py` 的控制台启动方式继续使用原来的账号选择和保存逻辑。

退出主管理服务会通知全部工作进程正常停止并清理连接；关闭浏览器不会停止机器人。主进程意外退出时，工作进程会因父进程管道关闭而开始清理，原生退出守护继续兜底。

## 页面功能

| 页面 | 功能 |
| --- | --- |
| 顶部账号选择框 | 切换管理对象、查看各账号运行状态 |
| 运行概览 | 发现已登录账号、逐行启动或停止、勾选批量启动；查看每个账号的连接、wxid 和进程；实时消息监控 |
| 插件管理 | 搜索插件、启用、停用、重载；编辑业务函数与 JSON 选项，保存生效或重置默认 |
| 群聊与会话 | 发送文字、选择成员进行真实艾特、查看群内身份；保存群 ID、群备注、会话白名单和记录开关；发现已收到消息的群 |
| 联系人 | 手动扫描当前账号好友，搜索昵称、备注、微信号、wxid 和标签；筛选标签、查看个人资料 |
| 模型与语音 | 配置 DeepSeek 或 OpenAI 兼容接口、语音合成与文本随机等待 |
| 运行日志 | 实时查看日志、筛选警告与错误、暂停滚动、清空当前视图 |

概览页直接在已登录微信列表中展示状态和启停操作。顶部账号选择框包含已登录的新账号，首次选择时自动准备独立配置。插件使用列表展示功能、状态和操作，模型的超时等设置放在“高级选项”中。窄窗口下导航收进菜单，列表自动换行，所有操作仍保留。

管理服务断开时，页面会提示当前展示的是上次读取的信息，将状态标为“待更新”，并暂停依赖服务的操作；连接恢复后自动更新状态和恢复操作。若重新启动了管理服务，刷新浏览器以取得新的页面会话。

插件描述在机器人启动前后、启停和重载后都会保留，并可按描述搜索。图库功能显示为“图库图片”，可在插件管理中开关、重载或编辑业务函数与配置，指令与图源见[图库图片](../messages/gallery.md)。

升级后先正常停止机器人、关闭管理台，再重新打开 `start_web.bat`；只刷新网页或重载插件不会更新核心 Python 模块。

## 网页修改与重置插件

在顶部选择机器人账号，进入“插件管理”，点击对应插件的“配置”。“业务代码”直接显示这个功能的处理函数，例如文字回复、发送图片、欢迎文案或生成总结；直接修改函数内的逻辑即可。初始化、连接、清单和其余源码不会显示。一个功能有多个业务函数时可按用途切换，“配置”页编辑该插件的 JSON 选项。点击“保存并生效”或按 Ctrl+S 保存。

机器人运行时保存会自动重载该插件，无需重启机器人。机器人停止时先保存，下次启动生效；停用的插件保持停用，除非同时将 `enabled` 改为 `true`。Python 语法、JSON 或插件加载失败时保留原代码和配置，编辑器显示错误，未保存的输入仍可继续修改。插件正在处理长任务时可能暂时无法重载，等任务结束后再保存。

“重置”或编辑器内的“重置插件”会先显示确认，再恢复当前安装版本的默认代码和该插件的模板配置。只影响所选账号的这一个插件，账号、群聊、模型密钥、聊天记录及其他插件配置保留。重置后的启用状态也按默认配置恢复。

框架会传入函数需要的消息、回复接口和已经准备好的业务数据。保留函数名称、参数和装饰器，只修改函数内部；保存时只替换对应函数，其他源码原样保留。修改按账号存放在各自工作目录的 `.runtime/plugin_code/`，不会改写项目内 `plugins/` 的默认代码，其他机器人不受影响；原版本留作本地备份。两个页面同时编辑时，旧版本会提示重新读取，避免覆盖新改动。单个业务函数最多 256 KiB；无需安装额外编辑器依赖。

升级本功能后需先正常停止机器人、关闭管理台，再自行打开 `start_web.bat`。

群聊备注按机器人账号保存在本地，不会修改微信中的群名称。在“群聊与会话”里为群 ID 填写备注，停止机器人后保存；备注会显示在已发现的群和发送消息的会话列表中。

## 发送文字和艾特成员

在顶部选中已连接的机器人，进入“群聊与会话”→“发送消息”：

1. 选择群聊或好友；列表包含当前账号已配置的群、本次连接已发现的会话和文件传输助手。进入页面后会自动读取，也可以点击“刷新会话”。未配置且本次尚未收到消息的群不会自动列出。
2. 选择群聊后会读取当前群成员。可按昵称、wxid 或身份搜索，勾选要艾特的人，每条最多 8 人；不勾选则发送普通文字。
3. 输入正文并点击“发送”。艾特使用真实成员 ID 和当前群昵称，支持微信的艾特通知；私聊不支持艾特。

成员表显示“群主”“群管理员”“普通群友”。成员缓存尚未就绪时仍可发送普通文字；需要艾特成员时，可以先在微信打开该群，再点击“刷新成员”。身份或完整名单尚未同步时显示未知或提示刷新。本群绑定称呼不改变真实群内身份，昵称也不作为权限依据。

超长正文按 UTF-8 字符边界拆成多条顺序发送，自动添加的艾特标签和通知只在第一条。每条沿用文本随机等待和会话白名单。发送状态独立查询，网络中断不自动重发；失败或结果不确定时先在微信核对，再决定是否重新发送。切换顶部账号会清空发送草稿和所选成员，已提交的发送仍属于原账号。页面加载、选择成员和刷新列表都不发送消息。

## 定时任务

在顶部选择账号，进入“定时任务”，选择任务类型并填写对应参数，再选择按分钟间隔或每天的本机时间，然后保存。可以编辑、启停和删除任务；列表显示下次执行时间和最近结果。当前内置发送文字和聊天总结插件的总结群聊；插件可以声明更多任务类型。会话 ID 可输入群 ID、好友 wxid 或 `filehelper`，输入框也提供已发现会话的候选项。

任务按机器人账号保存在本地，仅在管理台和对应机器人运行且微信已连接时执行；插件任务还需要相应插件已启用并加载。发送遵循会话白名单和文本发送节奏。关闭期间或断线时错过的任务不会补发，结果不确定时不会自动重试；同一任务上次还在运行时跳过重叠的下一次。编辑或重新启用任务会从保存时重新计算下次执行时间。已有文字任务继续有效。

## 扫描联系人

在顶部选择已连接的机器人，进入“联系人”，点击“扫描联系人”。页面读取当前电脑微信的本地好友缓存，显示昵称、备注、wxid、微信号和好友标签；点击行内“详情”可查看有值的性别、国家或地区、省份、城市、个性签名及好友描述。签名和描述分别显示，国家沿用微信缓存中的代码。

可搜索昵称、备注、微信号、wxid 和标签，或按好友标签筛选。每页显示 50 位联系人。没有标签时显示“无标签”；微信缓存中的标签名称暂时不能读取时显示“暂不可读取”，不会把它当作无标签。

联系人扫描目前已核对微信 **4.1.15.56**，旧版 4.1.15.13 的联系人目录尚未适配。

页面打开、切换页面和搜索均不自动扫描，也不强制联网同步好友。名单是否完整取决于当前微信缓存；未显示预期好友或标签时，可先在微信打开“通讯录管理”，再重新扫描。这个功能只读资料，不添加、删除好友或修改标签。

扫描结果仅保留在当前网页内。切换账号、机器人断开、服务断连或微信连接变化时清空，重新连接后需再次点击扫描。页面不读取头像、不输出原始 XML 或下载凭证，也不将联系人资料写入运行日志。

## 朋友圈

“朋友圈”页面只使用正在运行且已连接的机器人。只有一个时自动选择；多个时需要在“操作账号”中选择，独立于顶部的配置账号。切换发布账号或连接后清空草稿。

页面支持文字、JPEG/PNG 图片、公开或仅自己可见的预览。框架限制正文 1000 字、最多 9 张图片，单图 5 MiB、合计 20 MiB。预览不会发布；发布须在预览里再次点击，结果未确认时不会自动重发。

当前支持微信 **4.1.15.56 和 4.2.0.11**。两版均已核对仅自己可见的文字和图片发布；4.1.15.56 的公开纯文字已由另一账号确认可见，4.2.0.11 的公开发布尚未单独实测。旧版 4.1.15.13 暂不支持朋友圈发布。

读取时先在电脑微信打开朋友圈并等待列表加载，再点击“读取列表”。页面最多显示当前账号已加载缓存的 20 条记录，以及当前缓存中的点赞人和评论；不会主动翻页或获取完整历史，也不下载或展示图片。切换账号或连接会清除列表。

每条记录下可点击“点赞”，或展开“评论”、填写内容后点击“发送评论”。使用页面上选定的操作账号，评论最多 1023 个 UTF-8 字节（约 341 个常用汉字）。已经点赞的记录显示“已点赞”。读取列表本身不会发送互动。

互动结果显示在对应记录下。同一请求编号不会重复投递；断网或超时后只查询原请求，不重新发送。微信 **4.1.15.56** 支持点赞和普通文字评论；原生评论已核对发送回执及评论列表，已点赞跳过也已实测，首次点赞发送仍待实测。4.2.0.11 的点赞和评论尚未开放；尚未提供取消赞、回复指定评论或删除评论。

点击“预览”，核对账号、正文、图片和可见范围，再点击“发布”。页面等待完成回执和朋友圈编号后才显示成功；断网或超时会保留查询状态，不自动重发，结果不确定时先到手机朋友圈核对。图片上传使用微信缓存中的临时副本，原文件保持不变。

升级此功能后，需要停止机器人并关闭管理台，再重新打开 `start_web.bat`、启动机器人和刷新网页，以加载新的桥接 DLL。

## 消息监控

概览页的“消息监控”跟随顶部“当前账号”切换，约每 2 秒更新一次。每条记录显示本机记录时间、群 ID 或私聊 wxid、发送者的昵称与 wxid、消息内容。群内昵称优先使用当前群的绑定；无法识别作者时显示“未知发送者”，不会用群 ID 冒充用户 ID。

群消息还可显示发送者的群内身份，来自当前账号的群缓存，约每 15 秒检查；过期、跨连接或无法确认时不显示已确认身份。合并转发中的原作者不会继承转发者的群内身份。

文字显示完整正文（敏感密钥会隐藏）；多条长消息按传输大小分页，页面继续自动读取。图片、视频、语音、表情分别显示 `[图片]`、`[视频]`、`[语音]`、`[表情]`，文件显示文件名或 `[文件/分享]`。页面不展示媒体、不读取原始 XML、下载凭证或本机媒体路径。监控本身不触发媒体下载；原有图片和文件接收功能仍按各自配置运行。

[合并转发](../messages/forwarded.md)会展开为多条记录，显示原作者、原消息时间、转发者和文字；图片显示类型标记及下载状态。图片下载完成后在原记录上更新，不重复新增。原作者未提供可靠 wxid 时留空，不把名称或哈希值当作微信 ID。合集内的指令不会作为现场消息执行，也不会混入当天聊天总结。

收到撤回通知后，按当前账号、会话和微信原始消息编号关联记录，保留原内容、发送者和时间并标记“已撤回”。支持群聊和私聊，合并转发的展开记录也一起标记；已保存的媒体沿用原接收目录。未捕获、已超出缓存或缺少原始编号的消息显示“原消息未捕获”，不根据相似文字猜测。标记只作用于管理台缓存，不改变微信中的撤回操作。

默认开启的 `anti_recall` 插件提供文字和表情防撤回：文字、内置表情和 emoji 在原会话发送“撤回的消息是：原文”；已缓存的表情包直接重新发送，缓存失败时显示 `[表情]` 提示。图片、文件和已完整接收的语音分别由三个默认开启的插件补发。在“插件管理”可分别关闭，管理台标记仍保留。详细范围和升级方法见[防撤回与自动补发](../messages/recall.md)。

监控包含框架收到的消息和发送接口已接受的机器人回复，不读取微信旧历史。尚未加入支持列表或会话白名单的群，也会显示接收到的消息，便于复制群 ID；插件分发与聊天总结的记录范围仍按原配置控制。机器人发出消息的记录表示发送接口成功，不作为对方已收取的凭据。

可搜索 ID、昵称和正文；“暂停滚动”只停止自动滚动，消息仍继续更新；“清空视图”只清除当前页面。每个账号在工作进程内保留最近 1000 条，首次打开显示最近 200 条，之后增量更新；长正文最多显示 2000 字符。停止机器人后仍可查看该次管理服务的缓存，重新加载工作进程或关闭管理服务会释放缓存，不影响用于聊天总结的数据库。

消息监控和“运行日志”分别提供聊天记录与程序故障信息。群正文不因此写入原有运行日志。升级后如提示监控尚未加载，请停止机器人并重启管理台，再刷新页面。

## 配置生效与停止

插件开关、重载，以及插件编辑器中的业务函数和 JSON 选项，可在运行时保存生效。群聊、模型和发送节奏需要先停止当前机器人，等对应账号显示“未启动”后保存，再启动生效。保存前自动备份原配置到当前工作目录的 `.runtime/web/backups/`；原来的群成员资料和其他未编辑字段会保留。

API 密钥输入框留空表示保留已保存的密钥；勾选“清除已保存的密钥”才会删除。配置查询只返回“已配置”状态，不回传密钥本身。模型和语音服务是否可用仍取决于实际密钥、模型权限和网络。

大模型的“高级选项”可切换 JSON 模式、选择 `max_tokens` 或 `max_completion_tokens`，以及填写扩展参数 JSON。常规兼容接口将扩展参数留为 `{}`；官方 DeepSeek 的普通模型默认关闭思考，显式填写的思考设置优先，其他网关不会自动带入专属参数。遇到反复空正文可关闭 JSON 模式。接口地址前缀、配置示例和重试边界见[大模型配置](./configuration.md#大模型配置)。

群配置中每行一个 `@chatroom` ID。会话白名单非空时，新保存的支持群会自动加入白名单。移除支持群只停用对应群功能，不删除数据库中的称呼或聊天；如需阻止消息分发，也要从白名单中移除它。

“停止”会沿用框架的正常退出流程，先清理原生连接再卸载插件。页面显示“正在停止”时不要重复启动。若同一个项目已由另一个 `main.py` 运行，先在原终端输入 `quit`；管理台不会接管或强制结束其他实例。

关闭浏览器不会停止服务。退出管理服务时，在启动它的窗口按 Ctrl+C；机器人会同时收到正常停止请求。日志页面只显示本次管理服务启动后的最近日志，完整轮转日志仍在 `logs/bot.log`。“清空视图”只清空页面显示。

## 端口与访问范围

```powershell
python web.py --port 8877
python web.py --no-browser
```

默认端口 8765，占用时可以更换。服务固定监听 `127.0.0.1`，仅供本机浏览器使用；没有公网或局域网监听选项。页面和接口同源，管理操作验证页面会话令牌，令牌随服务重启失效，重启后刷新页面即可。

页面不调用外部字体、脚本或统计服务。账号、群配置、日志和配置备份都属于本地私有数据，继续遵循项目的 Git 忽略规则，不要上传到公开仓库。
