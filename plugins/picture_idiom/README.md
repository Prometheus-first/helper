# 看图猜成语

群内看图抢答小游戏。默认使用[飞飞看图猜成语 API](https://ffapi.cn/doc/ktccy.html)获取题图和固定答案，不需要 API 密钥；接口、图片下载或缓存写入失败时，自动回退到 26 道本地绘图题。也可以设置 `source: "local"` 完全使用本地题库。不调用大模型或生图接口。

在程序控制台输入 `enable picture_idiom` 启用，或将 `bot_config.json` 中 `plugins.picture_idiom.enabled` 设为 `true` 后重启。插件默认关闭，目标群需加入成员配置以及非空会话白名单。

| 群消息 | 功能 |
| --- | --- |
| `看图猜成语` 或 `/看图猜成语` | 开始游戏；已经开始时重发当前题图 |
| 四字成语或 `/猜 四字成语` | 参与抢答 |
| `提示` | 在线题先给首字，再给前两字；本地题先给图意，再给首字 |
| `换一题` | 揭晓本题答案并换题 |
| `公布答案` | 公布答案和图意，继续下一题 |
| `退出猜成语` | 结束本群游戏 |

答对时真正艾特首位答对的群友，并自动发下一题。同一轮出题和判题期间排队的后续答案不会被当成下一题答案。普通闲聊不处理；四字答案判错后，默认每群最多每三秒提醒一次，减少刷屏。

每群独立进行，重连、重载和停止会清除游戏进度。两个游戏插件都启用时，发送“看图猜成语”会切换掉本群成语接龙；发送“成语接龙”会切换掉本群看图猜成语，避免重复判题。判定用固定答案精确匹配，不调用模型猜测同义答案。反馈语气跟随本群人格，题图保持原样。

## 题源与配置

在线入口为 `https://ffapi.cn/int/v1/ktccy`。请求不携带微信账号、群号、玩家 ID 或群聊文本；服务商会收到正常 HTTP 请求的 IP 和请求头。题源服务由第三方维护，内容和可用性以实际返回为准。

```json
{
  "picture_idiom": {
    "enabled": true,
    "source": "ffapi",
    "timeout_seconds": 8,
    "wrong_reply_cooldown_seconds": 3
  }
}
```

示例是 `bot_config.json` 的 `plugins` 下的条目，不要覆盖整个主配置。

- `source`：`ffapi` 在线优先，`local` 仅本地。
- `timeout_seconds`：每次 HTTP 请求的超时，支持 1–30 秒，默认 8 秒。获取题目和下载图片分别请求，整轮耗时可能高于该值。连接或图片失败后，所有群共用一分钟的重试间隔，其间直接使用本地题。
- `wrong_reply_cooldown_seconds`：答错提醒间隔，支持 0–60 秒，0 表示每次提醒。

每群在线出题时避开最近 32 个已发送的答案，最多尝试两次，仍重复则使用本地题。在线题源不保证整场不重复；本地模式首题为“绕梁三日”，后续随机出题，一轮题库用完前不重复。在线与本地切换时会避开刚出的答案。

## 字体和题图

插件需要 Pillow 和本机中文字体，以便在线不可用时随时绘制本地题。优先使用楷体、微软雅黑和黑体，未找到字体时插件会明确报错。也可配置 `font_file`，相对路径以项目目录为起点；本项目不打包或分发系统字体。

题卡缓存在 `.runtime/picture_idiom/` 的账号隔离目录，在线图片在其 `online/` 子目录。只下载题源自身 HTTPS 地址，禁止重定向；响应限制为 64 KiB JSON、5 MiB 图片，图片只接受完整的单帧 PNG/JPEG，最多 400 万像素。下载后重新编码为 PNG、去掉元数据，文件名不包含答案。缓存只保存在本地且被 Git 忽略，不将第三方题图加入仓库；原生发送过程中不要清理，停止程序后可以清理。

回归测试使用模拟 HTTP 响应和临时生成的图片，不连接微信、不调用真实题源，也不附带聊天截图或个人数据。

题库在 `bank.py`，绘图规则在 `render.py`。添加新题需同时补充答案、图意提示、解释和绘图规则；修改已有图形后更新渲染版本号，避免复用旧缓存。
