# 文件防撤回

`anti_recall_file` 默认开启。普通文件附件已接收并下载成功后，若在原群聊或私聊被撤回，机器人重新发送缓存文件，并保留清洗后的原文件名，不额外发送文字提示。不依赖文本防撤回、大模型、人格或语音合成；合并转发、链接和其他分享消息不当作文件附件处理。

在网页“插件管理”独立开关“文件防撤回”，或在程序控制台使用：

```text
disable anti_recall_file
enable anti_recall_file
```

按机器人连接、会话和微信原始消息 ID 匹配，每个插件实例最多保留最近 1000 条文件的缓存引用及 1000 条撤回去重记录。同一撤回只补发一次；若通知先到，等正在下载的文件完成后再补发。下载失败、超过接收上限、缓存丢失、未知原附件或原连接已结束时无法恢复，不跨会话补发。

复用文件接收器已保存并校验的附件，沿用 20 MiB 接收/发送上限；文件名不会带上接收缓存的随机前缀。发送时生成保留原名称的临时快照，发送调用结束后清理该快照，不打开或执行附件。卸载、重载插件或重启会清空关联记录，不删除共用的接收文件。`chat_allowlist` 继续生效；关闭本插件且 `anti_recall` 仍开启时，沿用原来的文件名文字提示。
