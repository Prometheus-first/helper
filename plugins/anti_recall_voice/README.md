# 语音防撤回

默认开启，可在插件管理中独立关闭。群聊和私聊收到语音后，框架先保存入站消息自带的完整 SILK 音频，再按当前连接、会话和微信原消息编号关联撤回；撤回后补发原语音条，不调用大模型或语音合成。

只支持已完整捕获、封装和声明时长校验通过的语音。音频缺失、仍在分段接收、超出接收上限或格式不支持时不补发，不把文字提示当作成功恢复。暂不主动调用原生下载或读取语音数据库。已在微信 4.1.15.56 私聊验证自动补发和原录音正常播放；群聊共用接收与关联链路，尚未单独实测。

同一条语音只尝试补发一次；重复撤回通知和下载完成回调不会重复发送。切换账号或重新连接后不使用旧连接的撤回索引。插件关闭后清空索引，接收缓存由框架管理，不删除其他功能共用的文件。
