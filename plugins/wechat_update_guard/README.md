# 微信更新保护

插件默认关闭，仅针对核验通过的 Windows 微信 4.2.0.12 构建。启用后，管理台启动、控制台启动、网页启动微信以及机器人连接前都会检查保护；不再只等登录完成后加载插件。

保护占位保存在本机文件系统中，一次启用后，关闭机器人或重启电脑也会保留，不需要机器人常驻。后续启动检查用于确认已启用的保护仍然有效。范围是当前微信安装及当前 Windows 用户，不是永久禁止整台电脑上所有版本和所有用户的微信更新。

保护会保留一份通过哈希核验的原始更新器，用于恢复更新；把更新器原路径设为带本工具标记的目录，防止直接执行或按文件覆盖。微信当前用户的更新目录使用带标记的只读文件占位，阻止正常重建下载及解压目录。已识别的升级包及缓存备份会清除，不再保留大体积的待升级安装包；聊天数据、已安装的微信核心文件不在清理范围内。缓存处理支持已识别布局下不同的 4.x 数字版本，不再只处理 4.2.0.13。

保护作用于同一微信安装和当前 Windows 用户的更新缓存，影响该安装的全部微信账号。多账号同时启动会串行检查。未知内容、链接路径、指纹或更新器哈希不匹配时停止操作并报告；保护检查失败时，不通过网页登录入口继续启动微信。

也可以在微信启动前手动执行：

```powershell
python tools/wechat_update_guard.py --protect
```

解除本工具创建的两个占位并恢复原更新器：

```powershell
python tools/wechat_update_guard.py --restore
```

恢复时不会重新放回升级包。关闭插件不会自动解除已有保护；请使用上述恢复命令。仅移除本工具能核对标记的占位，不覆盖未知文件或目录。

旧版积累的缓存备份保存在当前用户的 `%LOCALAPPDATA%\helper-wechat-update-backup`。单独执行旧备份整理时仍保留最新一份：

```powershell
python tools/wechat_update_guard.py --cleanup-backups
```

`--protect` 的持久防护会清除全部已识别的升级缓存备份，而不是只整理旧备份。安装目录中的 `WeixinUpdate.exe.helper-disabled` 是恢复原更新器所需的小文件，始终保留。

这不是微信官方的更新开关。重新安装或修复微信、换安装目录、手动解除占位，或微信改用其他更新路径后可能失效，不能保证拦住所有未来更新方式。更改启动前检查代码后需重开管理台，单纯刷新网页不会重载 Python 进程。停用更新会影响后续安全更新。
