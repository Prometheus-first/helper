# 图片防撤回

`anti_recall_image` 默认开启。图片已接收并下载成功后，若在原群聊或私聊被撤回，机器人重新发送缓存图片，不额外发送文字提示。不依赖文本防撤回、大模型、人格或语音合成。

在网页“插件管理”独立开关“图片防撤回”，或在程序控制台使用：

```text
disable anti_recall_image
enable anti_recall_image
```

按机器人连接、会话和微信原始消息 ID 匹配，每个插件实例最多保留最近 1000 条图片的缓存引用及 1000 条撤回去重记录。同一撤回只补发一次；若撤回通知先到，等正在下载的图片完成后再补发。未知原消息、下载失败、缓存丢失或原连接已结束时无法恢复，不向其他会话发送。

复用图片接收器已保存的文件，沿用 20 MiB 和支持格式限制；是否为原图、标准图或缩略图取决于实际收到的图片数据。卸载、重载插件或重启会清空关联记录，不删除其他功能共用的图片文件。`chat_allowlist` 继续生效；关闭本插件时，若 `anti_recall` 仍开启，则沿用原来的 `[图片]` 文字提示。
