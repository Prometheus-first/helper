# 群聊语音回复

真正艾特机器人提问后，把 `mention_chat` 生成的回复交给 Fish Audio 合成，再通过已有微信语音接口发送。保持当前群人格和发言者前十条上下文，成功时只发送语音条；菜单、总结、成语接龙仍使用文字。

## 启用

1. 安装 `python -m pip install -r requirements-voice.txt`。
2. 将根目录的 `tts_config.example.json` 复制为 `tts_config.json`，填写自己的 Fish Audio `api_key`；正常启动也会补齐缺失模板。
3. 完成大模型和成员目录配置，把目标群加入成员配置；非空会话白名单中也要包含该群。
4. 在程序控制台输入 `enable mention_chat` 和 `enable voice_reply`，或在 `bot_config.json` 中开启这两个插件。
5. 在群里发送 `/查看音色`，再用 `/音色 完整名称` 选择；然后从成员列表真正艾特机器人提问。

`default_voice` 可以填写自己的默认音色名称或 ID，留空时先在群内选择。公开模板不绑定任何账号、群或个人音色。

## 群命令

| 命令 | 作用 |
| --- | --- |
| `/查看音色` | 个人音色与中文公开音色第一页 |
| `/查看音色 2` | 公开音色翻页 |
| `/查看音色 温柔` | 按关键词搜索 |
| `/查看音色 温柔 2` | 搜索结果翻页 |
| `/查看音色 全部` | 浏览各国语言音色，后面也可加关键词和页码 |
| `/音色 完整名称` | 切换当前群音色 |
| `/音色 ID` | 选择重名或已知 ID 的音色 |
| `/音色 关闭` | 当前群恢复文字回复 |

普通条目只显示名称，重名或名称被缩略时附 ID。名称选择优先匹配个人音色；公开重名音色要求用 ID 区分。音色按账号和群保存，重启、午夜清理和 `/清空` 均保留。

列表缓存十分钟，重载插件可刷新；公开列表受服务端浏览窗口限制，可改用关键词或 ID 查找。语音生成失败会回退文字；微信发送状态不确定时不自动重复发送。人格、音色、记录或连接变化会取消尚未发出的旧语音。

## 本地数据

模型生成的回复正文会发送给配置的 Fish Audio 服务。密钥只从本地 `tts_config.json` 读取，账号和群音色设置存入本地成员数据库。临时 WAV、SILK 在调用结束后清理，配置、数据库和缓存均不应提交。

完整说明见[语音文档](../../docs/messages/voice.md#fish-audio-文字转语音)。
